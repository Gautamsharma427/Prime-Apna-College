Your first engineering assignment
 Beginner → Production engineering









factoryflow.app


The concept: Build an internal platform that helps a business manage products, inventory, suppliers and orders.

Imagine a small company that sells electronic products. It needs a central system to:
- Maintain a product catalogue.
- Track inventory.
- Manage suppliers.
- Process customer orders.
- Monitor low-stock products.
- Generate operational reports.
- Eventually automate operations using AI agents.
This one project will let you practise almost everything appearing in the Apple and Babaclick job descriptions.

The technology stack
We're going to use one coherent stack rather than constantly switching technologies.
Layer	Technology
Frontend	TypeScript + React
Framework	Next.js
Backend	Python + FastAPI
Database	PostgreSQL
ORM	SQLAlchemy
Validation	Pydantic
Version control	Git + GitHub
Infrastructure	Linux + Docker
Testing	Pytest
AI	LLM APIs (later)

Why this combination? It covers the core technologies from Apple and Babaclick while providing a useful foundation for AI engineering.
The learning sequence: one project, progressively more advanced
The secret is that we won't build the entire application at once. We'll evolve the same application as your engineering skills improve.
1. Phase 1 — Python and programming fundamentals
   Start today
   Build the initial inventory engine.
   
   Learn:
   - Variables, functions and data structures
   - Dictionaries, lists and sets
   - Conditions and loops
   - Functions and modular code
   - Exceptions and input validation
   - File handling and JSON
   - Type hints
   Deliverable: A working command-line inventory manager.
2. Phase 2 — Engineering practices
   
   Learn:
   - Git, branches and commits
   - Project structure
   - Debugging
   - Unit testing
   - Refactoring
   - Documentation
   Deliverable: A tested, documented Python application.
3. Phase 3 — Databases
   
   Introduce PostgreSQL.
   
   Learn:
   - Tables, rows and relationships
   - SQL queries
   - Joins and indexes
   - Database constraints
   - Transactions
   - Database migrations
   Deliverable: Persistent product, supplier and inventory records.
4. Phase 4 — Backend engineering
   
   Introduce FastAPI.
   
   Learn:
   - HTTP and REST
   - GET, POST, PUT, PATCH and DELETE
   - Request and response validation
   - Authentication and authorization
   - Error handling
   - API testing
   Deliverable: A fully functional business API.
5. Phase 5 — Frontend engineering
   
   Introduce TypeScript, React and Next.js.
   
   Learn:
   - HTML and CSS
   - JavaScript fundamentals
   - TypeScript
   - Components and props
   - State management
   - Forms and API integration
   - Accessibility and responsive design
   Deliverable: The actual Forge web application.
6. Phase 6 — Production engineering
   
   Introduce Linux, Docker and deployment.
   
   Learn:
   - Environment variables
   - Containers
   - CI/CD
   - Logging
   - Monitoring
   - Security
   - Production debugging
   Deliverable: A deployed, maintainable application.
7. Phase 7 — AI engineering
   
   Introduce LLMs and agentic workflows.
   
   Learn:
   - LLM APIs
   - Structured outputs
   - Tool calling
   - Retrieval-augmented generation
   - Agent workflows
   - Human approval
   - Evaluation and reliability
   Deliverable: An AI operations assistant that can investigate inventory problems and recommend actions, with human approval before consequential changes.
8. Phase 8 — Advanced engineering
   
   Learn:
   - System design
   - Distributed systems
   - Caching
   - Concurrency
   - Performance optimisation
   - Scalability
   Deliverable: An architecture that can handle increasingly demanding workloads.
